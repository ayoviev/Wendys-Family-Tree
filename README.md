# Wendy's Family Tree

A web application for managing horses and their family tree / pedigree records.

## Tech Stack
- **Backend:** Java 25 + Spring Boot 4.0 + H2 Database
- **Frontend:** Angular 21 + Node.js
- **Testing:** JUnit 6 + AssertJ
- **Build:** Maven 3 + NPM

## About
Individual assignment for the Software Engineering Project (SE PR) course at TU Wien, Summer Semester 2026.
The app allows users to create, view, and manage horses along with their ancestors through a REST API backend and an Angular frontend.
